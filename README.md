# Temas para o Ludus

Este repositório foi criado pelo Ludus. Cada tema é um ficheiro em `temas/`, e
o `index.json` na raiz é a lista deles.

Não é preciso mexer aqui à mão: publicar um tema pelo Ludus escreve os
ficheiros sozinho. Mas nada impede — o formato é JSON simples, e uma alteração
feita aqui aparece na app da próxima vez que ela ler o repositório.

Para alguém instalar estes temas, basta colar o endereço deste repositório na
página dos temas do Ludus.
